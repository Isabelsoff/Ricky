# Rick  - UI Design App

Este repositorio contiene el diseño de interfaz (UI) de alta fidelidad para una aplicación móvil basada en el universo de Rick and Morty. 

##  Concepto de Diseño
El diseño fue elaborado en modo oscuro con acentos de color neón (verde portal y rosa) para darle un estilo moderno y cibernético.
